# Architecture Decision Records

**Authority:** Architect (Constitution Article 6).

This directory holds ADRs. Per D-6 in `DESIGN-DECISIONS.md`, ADRs record decisions; the constraints that emerge from a decision are captured as invariants in `docs/framework/arch/`, not as the ADR itself.

Content is deferred. The cross-cutting decisions taken during DEVAI's own design are recorded in the repo-root `DESIGN-DECISIONS.md`, which is the framework's own decision log; client-project ADRs land here when client work begins.

## Cross-repo governance ADRs

- [ADR-004-published-truth-operational-self-adoption.md](ADR-004-published-truth-operational-self-adoption.md) — exact-HEAD and age-bounded self-scorecard truth, fail-closed renderer/deployment provenance, explicit diagnostic persistence, managed-worktree isolation, deterministic Article 34 post-merge observation, dependency-security semantics, N/A-aware aggregation, evidence-backed invariant alignment, current-claims governance, and hybrid reusable-gate self-adoption (R21 W01, 2026-07-17). This ADR specifies behavior; it does not claim W01 implements it.
- [ADR-005-actions-run-evidence-promotion.md](ADR-005-actions-run-evidence-promotion.md) — exact-tested-tree Actions-run evidence as a backward-compatible D-117 manifest origin, shadow/full dispositions, fail-closed invalidators, two-stage Article-32 durability, and predeclared graduation/revocation without a parallel evidence authority (R22 W06, 2026-07-17). This ADR specifies behavior; it does not enable heavy-tier skipping.
- [ADR-003-runtime-authority-enforcement.md](ADR-003-runtime-authority-enforcement.md) — the constitutionally narrow DEVAI CLI/runtime authority contract. Freezes explicit human declarations and expiring sessions, trusted non-elevating machine derivation, version-bound materialized policy, deterministic test-over-source precedence, exact action/evidence contracts, issuer-authentic non-replayable final-boundary decisions, honest `cli-only`/conditional `host-integrated` posture, and the R19 migration state machine (R19 W01, 2026-07-15). This ADR specifies behavior; it does not claim W01 implements it.
- [ADR-DOCS-GOVERNANCE.md](ADR-DOCS-GOVERNANCE.md) — the cross-repo documentation publishing law. Classifies every governed repo as `library` or `application`, mandates Docusaurus for libraries, allows Jekyll opt-out for applications with documented ADR + sunset trigger, fixes the publish target as a same-repo `gh-pages` branch, and names `devai check docs-governance` as the hard-fail enforcement gate (R13 W01, 2026-05-26).
- [ADR-LOCAL-PUBLISH-WORKFLOW.md](ADR-LOCAL-PUBLISH-WORKFLOW.md) — the local-build → `gh-pages` publish contract. Specifies HOW the docs-governance law publishes: a deliberate-local `devai docs publish` CLI verb that runs detect → build → publish (orphan branch, force-push, no shared history with `main`), with idempotency gates and an explicit prohibition on CI-driven invocation. Companion mechanism to ADR-DOCS-GOVERNANCE Decision 4 (R13 W02, 2026-05-26).
- [ADR-CI-ECONOMY.md](ADR-CI-ECONOMY.md) — the cross-repo CI-economy law. Evidence-first pipelines (heavy tiers run locally, recorded via `devai record-run --chain`, verified — not re-run — by remote CI, with a never-silently-open fallback), the trust boundary that makes the short-circuit safe (SHA-bound evidence, trusted-actor allowlist, 24h freshness, policy-path guard, weekly full remote audit with revocation-on-red), four runner-economics rules (no macOS on PRs, mandatory cancel-in-progress concurrency, path filters where content is not gate-consumed, no daily/fail-by-design crons), the DB-isolation contract for concurrent integration tiers, the single-source reusable evidence-gate workflow exported by this repo, and `devai check ci-economy` as the enforcement verb (CI-economy round, 2026-07-10).
- [ADR-DOCS-IA.md](ADR-DOCS-IA.md) — the documentation information-architecture law. Defines the seven-section published layout (Start / Theory / Framework / Roles / Adopters / Reference / Meta), the binding framework/meta semantic split, the mirror-don't-fork source-of-truth rule, the root-file publish allowlist, the hand-authored sidebar discipline with `docs/_ia/categories.json` manifest, five named generators as part of the publish contract (aspect-grid, self-scorecard, test-matrix, skill-catalog, schema-browser), frozen-at-build dashboards with 30-day staleness threshold, the Constitution-versioning posture (activated in R14 because R14's Article 6 amendment is itself Article 40's first invocation), severity policy with soft-warn rollout for adopters, the five-rule extension to `check-docs-governance`, application-tier collapsed-section opt-out, and ADR-internal versioning policy (R14 W01, 2026-06-04).
