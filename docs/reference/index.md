## How to use this section

- **Looking up a workflow or selector.** Start at [CLI](./cli/), then follow the
  canonical descriptor or operator guide for its suite, preset, kind, slice, tier, or
  effect.
- **Looking for a sensor to score a cell.** Start at [Aspect grid](../theory/framework/aspect-grid.md) (under Framework), find the cell, follow the link to the sensor design note under `docs/theory/architecture/sensors/`. Then [sensors quick-ref](./sensors-quick-ref.md) has the flag-level detail.
- **Looking for a schema.** Start at [Schemas](../../law/schemas), find the schema by name or title, expand the JSON.
- **Looking for a script.** [Scripts](./scripts.md) lists every `pnpm` and `scripts/*.mjs` entry.
- **Looking for an example pack.** [Examples](./examples.md) catalogs the `examples/` directories.
