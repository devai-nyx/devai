# CLI migration

R-0007 is a fail-closed pre-release grammar change. Historical commands are lookup identities,
not aliases. A folded identity refuses the old route and names its governed successor; a
tombstone refuses dispatch; a retained identity remains canonical. Migration never carries
authority or consent into the successor invocation.

Use the complete historical identity, find its single generated row, and then re-evaluate the
successor's current inputs, effect, role, and consent. Stop on a missing, duplicate, conflicting,
or unparseable row. The generated population below is projected from the binding map and checked
against the action registry; edit those sources or the renderer, never the bytes between markers.
