# Meta

> §7 is DEVAI's self-application surface. Per [Constitution Article 36](../reference/law.md), the framework must apply itself to its own development. ## Article 36 framing

The framework's substrate machinery (F1 specs, F2 code, F3 tests, F4 inventory, F5 harness) is _itself_ an F2 plant for the meta-framework that scores DEVAI as a client of itself. Every sensor that scores an adopter's substrates also scores DEVAI's substrates. Every gate that an adopter must pass, DEVAI passes too — or its scorecard surfaces the failure.

This section is the **receipt** that DEVAI lives by what it preaches. If DEVAI cannot pass its own gates, the framework has not earned the right to demand them of adopters.

## Audience

§7 Meta is for:

- **Contributors to DEVAI.** Read [operations](./operations/README.md), then inspect the current repository state and focused evidence.
- **Auditors of DEVAI's self-application.** Start with the canonical `work/rounds/R-0001/plan.md` status and the active round's exact-candidate evidence. Use the [self-scorecard](../start/status.md) only when its displayed subject, render, and freshness provenance match that candidate; [test matrix](./index.md) describes suite structure rather than release truth.
- **Adopters curious about how DEVAI itself runs.** §7 doubles as a worked example — what an adopter's §7 _should_ look like. Not authoritative for any specific adopter, but illustrative.

Adopters who want the framework reference go to [§3 Framework](../theory) instead.
