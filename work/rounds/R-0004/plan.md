## Acceptance

- One authoritative action ID source feeds CLI, effects, sensors, docs generation, and
  tests.
- All canonical schemas pass the full recursive linter, including marker and
  dereferenced-publish identity checks.
- Every live sensor resolves an emitter and design note; diagnostic/cell standing is
  explicit.
- Every action is deliberately kept, folded, or tombstoned with migration guidance.
- Leaf help reaches the selected command without authorizing mutation.
- Root build/test use bounded registered processes and cannot smuggle arbitrary commands.
- Fixed-group validation derives exactly eleven members: the ten split public packages
  plus the core façade.

## Stops

Stop on behavior deletion to hit a target count, local mirrored IDs, unregistered
subprocesses, a core dependency cycle, implementation logic in the façade, a package
publish, or coverage-threshold change.

## Exit claim

The governed surface and package topology are implemented and tested. Nothing is
published, deployed, or ready; all unchanged coverage floors remain required.
