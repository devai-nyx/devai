# Wave 2 — Inspector red contracts

## Agents

Spawn three `gpt-5.6-sol` agents at `xhigh`, each as Inspector in a dedicated worktree:

1. Surface/migration Inspector — action population, old-route rejection, seven-domain help, hidden plumbing.
2. Semantics/executor Inspector — suite/preset membership, vocabulary, task-round
   containment, executor kinds, model routing, effects and consent.
3. Output/docs-contract Inspector — action envelope totality, execution evidence,
   generated/built parity, documentation enumeration coverage.

Each agent receives a disjoint test-file allowlist. No production, law, docs, scripts, or
generated file edits are allowed.

## Required reds

- Exact target population and every one of the 147 migration rows.
- `f5`, `--allow-publish`, check `--profile`, and sense `--set` fail with exact guidance.
- Root help shows seven domains; task/catalog require expanded help.
- Suite/preset descriptor policies do not yet satisfy frozen membership.
- `sweep` excludes write-capable kinds and reports them.
- Missing/mismatched/inactive `round_id` blocks every task operation.
- Missing or malformed executor contracts block task creation and dispatch.
- Routine execution is shell-free and does not invoke an LLM.
- Agent `exact` forbids substitution; `preferred` uses only its explicit ordered
  allowlist; `policy` requires a named/versioned routing policy.
- Unknown runtime/model/effort combinations and unavailable models fail closed.
- Requested executor data and resolved execution evidence cannot be conflated.
- Human completion requires evidence; composite cycles and cross-round children fail.
- Legacy task records never receive inferred round/executor/model/effort values.
- `round run` owns normal task advancement and resource rollback.
- Migration execution cannot pass as a read action.
- Every enumerated documentation category, including executor kinds, selection modes,
  runtimes, rostered models, and supported efforts, has an exact completeness/bijection check.
- Built/source catalog disagreement is loud, never skipped.

Read the red output before every Inspector commit.
