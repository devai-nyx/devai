The Owner directs R-0006 to replace the otherwise-required Claude Opus 5 close review
with an independent Codex review. An independent Codex agent using the explicit
`gpt-5.6-sol` model must perform the read-only exhaustive exact-candidate close review,
and every actionable finding must be governed and repaired before source publication.

## Narrow substitution

For R-0006 only, this rider replaces the `claude-opus-5` selector requirement in
OM-003, OM-012, the shared execution contract, the R-0006 plan and orchestrator prompt,
and the R-0006 close-control policy. It does not manufacture or preserve a Claude,
Opus, cross-provider, or prior-candidate PASS. The new record must identify the exact
Codex model, candidate commit, governed range, manifest identities, findings, topic
dispositions, and verdict truthfully.

Every OM-011 and OM-012 review-quality control remains binding: the reviewer is
independent and read-only, recomputes the complete mechanically generated topic census,
continues after blockers, dispositions every topic exactly once, rechecks all prior
finding classes, and issues PASS only with zero failed or blocked topics and zero P0 or
P1 findings. A FAIL or BLOCKED verdict invalidates the candidate and returns to
complete-class role-pure repair. There is no forced PASS and no numeric cycle cap.

## Publication and closure boundary

Only a mechanically valid exhaustive Codex PASS permits the existing review envelope,
source PR, exact-SHA CI, source merge, exact-main CI, closure-only PC-0007 PR, closure
merge, and final exact-main ceremony to continue. PC-0007 still binds the all-green
source merge, uses DII-207 as declaration and the current Architect closing decision,
and records release disposition `none-needed`.

This mandate does not authorize package publication, tags, GitHub Releases, Pages or
other deployment, evidence promotion or reuse, real-stynx mutation, predecessor
mutation, or R-0007+ work. R-0006 closure remains the terminal boundary.
